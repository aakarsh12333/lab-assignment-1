📝 Todo App

A simple and efficient Todo List Web Application built using HTML, CSS, and JavaScript. This app helps users manage daily tasks with ease by adding, deleting, and marking tasks as completed.

🚀 Features
➕ Add new tasks
✅ Mark tasks as completed
❌ Delete tasks
💾 Data stored in browser (Local Storage)
🎨 Clean and responsive UI
🛠️ Tech Stack
HTML – Structure of the app
CSS – Styling and layout
JavaScript – Functionality and logic
📂 Project Structure
todo-app/
│── index.html
│── style.css
│── script.js
⚙️ How It Works
Enter a task in the input field
Click the Add button
Your task will appear in the list
Click on a task to mark it as completed
Click delete button to remove it
